TODO App

Project Description

This is a simple TODO App made using HTML, CSS and JavaScript.

Features

- Add new tasks
- Select task priority
- Display tasks in a table
- Delete tasks
- Save tasks using Local Storage
- Data remains saved after refreshing the browser

Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

Local Storage

The TODO App uses Local Storage to save the task data in the browser.
When a task is added, it is stored in Local Storage, so the data does not disappear after refreshing the page.

How to Run

1. Open the project in VS Code.
2. Open "index.html".
3. Run the project using Live Server.
4. Add tasks and select their priority.
